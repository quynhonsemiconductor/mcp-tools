# AWS Knowledge Remote MCP Server

## Description
This is a remote, fully-managed MCP (Model Context Protocol) server hosted by AWS that provides access to the latest AWS documentation and guidance, including API references, What's New posts, Getting Started content, Builder Center material, blog posts, architectural references, and Well-Architected best practices.

## Prerequisites
- Network connectivity to `https://knowledge-mcp.global.api.aws`

## Additional Resources

- AWS Knowledge MCP Server Endpoint: https://knowledge-mcp.global.api.aws
- Complete Documentation: https://awslabs.github.io/mcp/servers/aws-knowledge-mcp-server
