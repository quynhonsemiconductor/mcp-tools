# Resource Reference

QNSC MCP Toolkit provides MCP resources for accessing logs, configuration references, and other contextual data. Use the navigation to browse available resources by category.

## Using Resources

Resources are available through the MCP protocol and can be read by your AI assistant to access reference data, logs, and other useful context.

## Listing Resources

You can list all available resources from the CLI:

```bash
# List all resources
qnsc-mcp list-resources

# Output as JSON
qnsc-mcp list-resources --json
```
