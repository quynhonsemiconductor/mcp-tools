# Prompt Reference

QNSC MCP Toolkit includes reusable prompt templates that provide structured guidance for common tasks. Use the navigation to browse available prompts by category.

## Using Prompts

Prompts are available through the MCP protocol and can be invoked by your AI assistant. They provide pre-built templates for workflows like code review, architecture analysis, and more.

## Listing Prompts

You can list all available prompts from the CLI:

```bash
# List all prompts
qnsc-mcp list-prompts

# Output as JSON
qnsc-mcp list-prompts --json
```
